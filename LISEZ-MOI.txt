1. Chacun ouvre l'URL éditeur
2. Choisit son rôle (Admin / FCTP / NETPC / Visibilité)
3. Admin, FCTP et NETPC collent le même TOKEN GITHUB partagé
   (tu leur donnes en MP ou SMS, ne jamais sur mail)
4. L'app charge les 20 rues. Chacun peut :
   - Cocher le statut de SES chapitres
   - Déposer des fichiers dans SES chapitres
   - Voir TOUS les chapitres et fichiers des autres (en lecture)
5. Chaque action = commit GitHub automatique
6. Les viewers (Joël, MOE…) rafraîchissent toutes les 60 s
