══════════════════════════════════════════════════════════════════
  DÉPLOIEMENT GITHUB (pour que Joël voie en temps réel)
══════════════════════════════════════════════════════════════════

ÉTAPE 1 — Créer le repo GitHub
   • Dans ce dossier, lance : /init-github
   • Nom suggéré : doe-matabiau-app
   • Visibilité : public (sinon Joël devra se connecter)

ÉTAPE 2 — Activer GitHub Pages
   • GitHub → repo → Settings → Pages
   • Source : branch main / root
   • Save

ÉTAPE 3 — Créer un Personal Access Token (PAT)
   • github.com/settings/tokens → Generate new token (classic)
   • Nom : "DOE MATABIAU App"
   • Scope à cocher : repo (en entier)
   • Durée : 1 an (ou pas d'expiration)
   • Copier le token (ghp_...)

ÉTAPE 4 — Ouvrir ton URL admin
   • https://<ton-user>.github.io/doe-matabiau-app/index.html
   • Coller le token → se connecter

ÉTAPE 5 — Donner le lien à Joël
   • https://<ton-user>.github.io/doe-matabiau-app/viewer.html
   • Joël peut installer l'app sur son téléphone (menu navigateur → "Ajouter à l'écran d'accueil")
   • Il verra l'avancement en temps réel (recharge auto toutes les 60 s)

══════════════════════════════════════════════════════════════════
  EXCEL
══════════════════════════════════════════════════════════════════

Généré 2 façons :
  A) Depuis l'app  (bouton 📊 Exporter Excel)
     → Fichier téléchargé par le navigateur (snapshot à jour)
  B) Depuis Python (exports/gen_excel_template.py)
     → Fichier vierge avec formules Excel natives (COUNTIF)

Le template exports/Suivi_DOE_Partiel_MATABIAU.xlsx est utilisable
seul si tu veux saisir à la main dans Excel plutôt que dans l'app.
Dans ce cas, saisir "X", "P", "R" ou "N/A" dans les cellules du
Dashboard — les formules %, Statut, Récap se recalculent seules.
